# Hockey Auto Editor — 0.2.0 (тестовая версия)

Локальная Windows-программа для монтажа хоккейных разборов. Версия 0.2 объединяет поиск голов, несколько исходных матчей внутри одного разбора и новый интерфейс «Материалы → Проверка → Экспорт».

Принятая пользователем **0.1 остаётся в `main` без изменений**. Разработка и Windows-сборки 0.2 находятся в ветке `version-0.2`. Отдельная версия 0.1.1 не выпускается.

## Новое в 0.2

- Загрузка нескольких записей с командами в порядке табло и датой. Одну запись можно использовать в нескольких разборах.
- Автоматический поиск области счёта и изменений табло; уточнение момента по остановке игрового времени. Записи без звука поддерживаются.
- Локальные модели RapidOCR включены в приложение. Видео не передаются в облако, API-ключи не нужны.
- Привязка найденных эпизодов к фразам сценария и конкретной исходной встрече.
- Экран проверки кандидатов: просмотр в видеоплеере Windows, замена эпизода, поправка границ, возможность оставить ведущего.
- Сохранение поиска для повторного использования; изменение файла или области счёта аннулирует старые результаты.
- Ручное уточнение области двух цифр, если автоматическое распознавание не нашло табло.
- Чтение проектов 0.1. По умолчанию предлагается сохранить отдельную копию с суффиксом `-0.2`.

## Монтаж

Сохраняются автоматические тайминги речи, синхронное сокращение пауз, очистка голоса, цветокоррекция, музыка с приглушением, наезды 100–120% с промежутками, мягкие переходы, анимированное появление/уход и лёгкое покачивание плашек. Экспорт выбранного разбора: MP4 720p/1080p, 30 кадров/с, SRT и JSON разметки. Готовые клипы также можно добавлять вручную.

## Запуск

Скачайте `HockeyAutoEditor-Windows` из успешной сборки ветки `version-0.2` в GitHub Actions. Распакуйте оба уровня ZIP в новую папку и запустите `HockeyAutoEditor.exe`. Сохраните папку `_internal` рядом с программой. Python и FFmpeg отдельно устанавливать не нужно.

## Границы тестовой версии

Поиск использует табло и игровой таймер, а не отслеживание шайбы. Повторы, отменённые голы, длинное отсутствие табло и необычная графика требуют проверки. GOAL-баннеры дают только кандидатов. Неуверенные события не попадают в монтаж без выбора пользователя. Полное отсутствие нужной записи оставляет ведущего с явной отметкой в таблице.

Первый приёмочный тест — полная запись СКА — «Лада» и сравнение с четырьмя одобренными клипами; затем другая встреча и несколько источников. Полная запись в текущей рабочей среде отсутствует: успешные автоматические проверки сборки **не заменяют** этот тест.

- Windows, Python 3.11, CPU-обработка; CUDA не требуется. Целевая конфигурация: i5-11400F, GTX 1070, 16 ГБ. Скорость на ней ещё предстоит измерить.
- Ведущий: до 15 минут; каждая запись матча: от 5 секунд до 4 часов. Анализ длинных матчей занимает время и место для временных кадров.
- В 0.2 поиск рассчитан на горизонтальное табло сверху или снизу, счёт 0–15. Порядок команд задаётся при добавлении файла.
- Сценарий должен в основном соответствовать произнесённой речи. Дубли, пропуски и большие перефразирования требуют проверки.
- Новые проекты версии 2 не открываются в старой программе 0.1. Исходные видео хранятся отдельно от проекта.
- Впереди: чтение документов материалов, встроенный плеер и монтажная шкала, объединение разборов со вступлением и концовкой в полный выпуск.

## Разработка

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/check_ocr.py
python scripts/check_gui.py
python main.py
```

OCR-интеграция и интерфейс проверяются на Windows. `python scripts/build_windows.py` создаёт папку программы и ZIP, проверяет уже упакованный EXE, модели OCR, русский синтезатор анализа и FFmpeg. GitHub Actions также проверяет поиск на синтетической видеозаписи и реальную нарезку найденного эпизода.

Лицензии и компоненты: [THIRD_PARTY.md](THIRD_PARTY.md). Пользовательские видео и сценарии в репозиторий не включены.
