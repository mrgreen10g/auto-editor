# Auto Editor — 0.3.0

Локальный автоматический монтаж спортивных разборов для Windows. Текущий шаблон работает с хоккеем; футбольный шаблон запланирован отдельно.

Версии 0.1 и 0.2 сохранены в своих ветках. Обновление 0.3 находится в `version-0.3`.

## Что изменилось

- Игровые сцены ищутся по изображению и движению независимо от табло. Ошибка чтения счёта больше не отменяет подбор обычной игры.
- Подбор: точный уверенный гол → обычная игра из этой встречи → другая загруженная встреча. Приоритет у записи с участием нужной команды. Архивная замена явно обозначается на видео и в списке эпизодов.
- Краткие упоминания прошлых встреч также создают задания на вставки. Повторное использование одного резервного фрагмента откладывается, пока есть другие кандидаты.
- Краткие плашки для бросков, результатов, коэффициентов, прогнозов и условий. Текст о травмах сохраняется полностью. Для длинных фраз вне известных шаблонов автоматическая плашка может быть пропущена, чтобы не исказить смысл; текст можно задать вручную.
- Новые информационные плашки с мотивами разметки льда. Карточка матча отличается размером и композицией, поддерживает логотипы двух команд.
- PNG/JPEG/WebP вписываются в единый размер. Масштабирование не восстанавливает детали плохого оригинала; для чётких логотипов лучше использовать крупные исходники.
- Автоповорот ведущего: учитывается ориентация файла, затем сравниваются лица в нескольких кадрах. Если уверенного результата нет, ориентация сохраняется, а в журнале появляется объяснение. Ручной поворот остаётся доступным.
- Готовые вставки по умолчанию скрыты; доступны в настройках совместимости.
- Во вкладке «Речь и плашки» убрана двусмысленная отметка «Проверить». Двойной щелчок редактирует текст плашки; замечания к таймингам остаются в журнале.
- Дата встречи необязательна. Подбор опирается на команды; при нескольких записях одних команд источник можно заменить вручную.
- Подсказки «?» на карточках и при наведении на основные кнопки.

## Запуск

Скачайте `AutoEditor-Windows` из успешного запуска Windows build для ветки `version-0.3`. Распакуйте архив и вложенный ZIP в новую папку, запустите **AutoEditor.exe**. Папку `_internal` рядом с программой не удаляйте. Python, FFmpeg и модели отдельно устанавливать не нужно.

## Сохранённые возможности

Несколько исходных матчей и несколько разборов в проекте; автоматическая разметка речи; сокращение пауз; очистка голоса; наезды 100–120% с промежутками; мягкие переходы; анимация появления, ухода и покачивания плашек; музыка с приглушением; цветокоррекция; экспорт выбранного разбора в MP4 720p/1080p, 30 кадров/с.

Проекты 0.1/0.2 открываются в 0.3. При сохранении предлагается отдельная копия `-0.3.hockeyproj`. Обратная совместимость нового формата со старой программой не предусмотрена. Пользовательские медиа не включены в репозиторий.

## Практические ограничения

Для вставок нужна хотя бы одна читаемая запись с пригодными кадрами. Программа не может получить игру из чёрного или повреждённого файла. Различение игры, повторов и остановок остаётся эвристическим; для слабого совпадения в списке есть пояснение. При отсутствии точного гола резервная сцена иллюстрирует рассказ, но не заявляется доказательством конкретного события.

Распознавание работает локально на CPU. Ведущий — до 15 минут, каждая запись матча — до 4 часов. Длинные записи требуют времени и места для кеша. На целевом компьютере i5-11400F / GTX 1070 / 16 ГБ скорость измеряется на пользовательском материале.

## Разработка

Python 3.11. `pip install -r requirements.txt` → `python main.py`.

`python -m unittest discover -s tests -v` — проверки логики и реального FFmpeg-экспорта. `scripts/check_ocr.py` — Windows-интеграция локального OCR, поиска, нарезки и монтажа. `scripts/check_gui.py` — сценарии интерфейса и компактное окно. `scripts/build_windows.py` собирает и проверяет упакованный EXE, модели OCR и ориентации.
