# Hockey Auto Editor — 0.1

Локальное приложение для Windows, которое собирает один разбор матча из записи ведущего, сценария и готовых игровых вставок.

## Что работает в первой версии

- Сохранение и открытие проекта, несколько разделов-разборов в одном проекте.
- Поиск текста выбранного разбора внутри записи ведущего до 15 минут. Пользовательские таймкоды не нужны.
- Автоматическая разметка фраз по сценарию и аудио, с отметками неустойчивых совпадений.
- Синхронное сокращение пауз в изображении и звуке.
- Мягкая очистка голоса от шума, удаление низкого гула, выравнивание громкости.
- Игровые вставки по словам сценария; автоматические информационные плашки и редактирование их текста.
- Плавные наезды 100% → 120% с паузами между ними.
- Мягкие переходы к игровым фрагментам и обратно.
- Анимированные вход/выход и лёгкое покачивание всех плашек.
- Музыка с приглушением под голос, лёгкая цветокоррекция, ручной выбор поворота исходника.
- MP4 в 720p/1080p, автоматические SRT и JSON с разметкой рядом с результатом.
- Отмена обработки; исходные файлы и существующие MP4 не перезаписываются.

## Что ещё впереди

Это первая сборка монтажного движка, не весь запланированный продукт. Автоматический поиск голов в полных записях матчей ещё не реализован: сейчас нужны готовые игровые фрагменты. Также впереди чтение документов «Материалы», объединение разборов в полный выпуск, шаблоны вступления/концовки и встроенный видеоплеер с редактируемым таймлайном. В этой версии результат открывается в обычном видеоплеере Windows.

Сопоставление ожидает, что произнесённый текст в основном следует сценарию. Пропущенные абзацы, переснятые дубли и сильно изменённый текст требуют проверки. Совпадение двух вариантов анализа — диагностический признак, а не гарантия точности.

## Запуск пользователем

Скачайте Windows ZIP из успешной сборки в **Actions → Windows build → Artifacts**. Извлеките всю папку ZIP и запустите `HockeyAutoEditor.exe`. Папку `_internal` рядом с EXE нужно сохранить. Python, FFmpeg и консоль устанавливать не требуется. Анализ и экспорт работают локально, без загрузки пользовательских видео в облако.

Пошаговая инструкция: [docs/QUICKSTART_RU.md](docs/QUICKSTART_RU.md).

## Для разработки

Python 3.11, зависимости из `requirements.txt`. На Windows tkinter входит в обычную установку Python.

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python main.py
```

Проверка упакованной сборки без интерфейса:

```sh
HockeyAutoEditor.exe --self-test report.json
```

Локальная сборка Windows: `python scripts/build_windows.py`. Сборка Windows должна выполняться на Windows. GitHub Actions запускает тесты, собирает приложение и проверяет уже упакованный EXE, включая русский голос анализа и FFmpeg.

## Технические границы

- CPU-обработка; CUDA не требуется. Реальная скорость на целевом компьютере должна быть измерена.
- Нейросетевая модель и сетевые API не используются. Внутренний синтезированный голос служит только для поиска фраз и не попадает в готовый ролик.
- Уровень шумоподавления регулируется; сильное эхо, клиппинг и перекрывающая голос музыка не считаются автоматически исправимыми.
- Локальный кеш анализа сохраняется для повторных экспортов. В репозиторий не включены пользовательские видео, сценарии и проекты.
