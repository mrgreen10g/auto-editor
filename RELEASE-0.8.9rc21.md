# 0.8.9rc21

База — законченная 0.8.9rc20. Динамический монтаж отложен; план сохранён в docs/DEFERRED_DYNAMIC_EDITING.md.

- Громкость фоновой музыки: ползунок 0–100% на ПК и в Mini App. Уровень применяется после нормализации, без последующего автоматического выравнивания музыки. 0% выключает музыкальную дорожку. Старые уровни из проектов и шаблонов переводятся в проценты.
- «Реже»: максимум 10 игровых вставок на всё итоговое видео, равномерно по монтажной дорожке. Это касается и явных игровых эпизодов. Плашки, факты и прогнозы не сокращаются. На финальном экспорте ограничение действует также для старых сохранённых разметок.
- Состояние выпуска: резервная копия служебных данных, восстановление пропавшего mobile-draft.json, исправление устаревших идентификаторов в истории. Повторный импорт папки без старых служебных данных создаёт новый черновик из исходников, не удаляя видео.
- Ведущий: строки с выбором видео из папки, загрузкой с телефона или браузером файлов сервера; плюс добавляет части без ограничения их количества. Части можно переставлять и убирать.
- Микрофон: одна общая запись для выбранных частей; либо звук камеры. Для каждой камеры используется существующая проверка синхронизации по звуку. Поддерживаются видео и аудио микрофона.
- Выбор частей и микрофона доступен при выборе папки выпуска; в сводке показаны количество частей и микрофон.
- Браузер файлов и папок открывается рядом с соответствующим полем, а не наверху страницы. Исправлена ошибочная разметка HTML в head.

Проверки включают восстановление состояния, порядок частей, замену микрофона, реальное усиление аудио FFmpeg, общий лимит вставок и мобильный сценарий загрузки/выбора файлов.
