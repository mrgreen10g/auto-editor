# 0.7.29rc1 — Telegram и автоматический поиск таймингов

## Подключение

В «Оформление и звук» откройте «Telegram и автоматизация → Настроить уведомления».
Создайте отдельного бота через @BotFather командой /newbot. Вставьте токен в редактор (никому не пересылайте его). Откройте своего бота и отправьте одноразовую команду, указанную в окне настроек. Нажмите «Найти мой чат», затем «Тестовое уведомление». Включите отправку, выберите события и сохраните настройки.

Уведомления общие для всех шаблонов: начало этапа, фрагменты готовы, плашки готовы, нужна проверка, рендер завершён, ошибка, отмена. Сообщения содержат название выпуска и время обработки. Исходные видео, сценарии, расшифровки и полный журнал ошибок не отправляются. Токен защищён Windows DPAPI и хранится отдельно от проектов; перенос на другой Windows-профиль требует повторного подключения.

Редактор должен оставаться запущенным на сервере. На iPhone разрешите уведомления Telegram для чата с ботом. Сетевая отправка фоновая, с ограниченными повторами при временной ошибке; её сбой не прерывает монтаж. Повторы сообщений внутри одного запуска этапа отсекаются, но при неопределённом сетевом ответе Telegram возможен дубль. Очередь не сохраняется после закрытия программы. Настройка не управляет сервером удалённо.

## Автопереход

После успешного поиска фрагментов автоматически начинается поиск таймингов, если во всех выбранных разборах не осталось неразрешённых фрагментов или незавершённого поиска. Ошибка и отмена блокируют переход. Если запросов на вставки нет и поиск штатно завершён, переход также разрешён. Автоматическое подтверждение сомнительных фрагментов не выполняется. Рендер не запускается автоматически.

Опцию можно выключить в том же окне. Она включена по умолчанию и работает без Telegram. После ручного решения спорных моментов кнопку поиска таймингов по-прежнему нажимает пользователь.

## Следующий этап (не реализован в этой версии)

Проверка клипов и плашек с телефона, защищённые кнопки подтверждения, команда запуска рендера и доставка готового видео. Нужны проверка chat/user ID, привязка каждой кнопки к версии проекта и запрет повторного применения устаревших решений. Обычный облачный Bot API ограничивает загрузку видео 50 МБ; для больших оригиналов потребуется ссылка на защищённое хранилище либо отдельный Local Bot API Server (до 2000 МБ).
