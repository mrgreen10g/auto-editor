# 0.8.9rc22 — информационные плашки РУ футбола

- Дополнительные факты из исходного сценария: таблица, очки, результаты, форма, удары, владение, голы, состав, травмы, удаления, календарь, мотивация и тактические аргументы.
- Числительные отображаются цифрами. Плашка содержит контекст фразы: предположения и риски не выдаются за результаты, отсутствующие данные не вычисляются.
- Тёмные информационные панели, крупные показатели, цветовые акценты, отображение серии и владения. Существующая анимация появления/ухода сохраняется. Субтитры и верхняя навигация не добавлены.
- Тихий синтезированный звук появления, громкость 0–100%; 0 выключает звук. Звук не применяется при отключённой анимации.
- Настройки в основной программе и Mini App: «Расширенные факты · РУ футбол», «Громкость инфографики».
- Сохранённые проекты совместимы. Чтобы добавить факты к старому выпуску, заново определить плашки: кэш распознавания речи не сбрасывается.

Область изменения: РУ футбол, горизонтальные выпуски. Другие спортивные и языковые шаблоны сохраняют прежнее оформление.

Проверка материалов: 1.txt — 110 фраз / 70 информационных плашек; 3.txt — 95 / 62; 5.txt — 106 / 68. 2.txt пуст; 4.txt дублирует 3.txt. Это число дополнительных фактических фраз, не итоговое число прогнозов/служебных плашек. Все панели отрисованы без обрезания текста.

Предоставленный текст text.txt относится к другому выпуску, а файл «тестовый фрагмент (сценарий).txt» пуст. В демонстрационном видео использованы вручную проверенные интервалы трёх фактов из реального вступления. Демонстрация проверяет оформление и экспорт, не точность автоматического распознавания речи.
