# 0.7.17rc1 — УЗ-футбол, речь и архивный монтаж

## Исправления

- Telegram: при обрезке стыков сохраняются короткие положительные строки речи,
  а ссылки плашек и базового снимка перенумеровываются. Плашка больше не проверяется
  против чужой строки. Проверка её границ остаётся включённой.
- Общий импорт TXT/DOCX (без Word, макросов и внешних запросов). УЗ-футбол удаляет
  русские редакторские блоки, подписи спикера, URL, разделители и технические цитаты.
  Номера матчей не входят в название пары.
- Футбол: Tanlovim, порядковые варианты, победа, не проиграет + тотал;
  распознавание будущего выбора без обязательного слова «мой выбор». Исторический
  Ramos больше не совпадает с условием ставки «mos».
- Итоги могут начинаться с «Demak/Deming bugungi … tanlov…». Упоминание Xullas
  внутри третьего разбора само по себе не обрезает этот разбор. Слитые ASR-повторы
  нескольких ставок разделяются по принадлежности команд.
- УЗ-футбол допускает несколько записей. Точная пара имеет приоритет, при её
  отсутствии используются назначенные архивы соответствующей команды.
  Вставки обозначаются «Архивные кадры»; счёт из таких кадров не объявляется точным
  подтверждением сказанного результата. Посторонний спорт не подмешивается.
- Хоккей: варианты произношения клубов, окончания числительных, составные ставки,
  выделение главной ставки вместо её частичных дублей; представления и повторы.
  Архивный игровой фрагмент возможен при рассказе о форме/тактике без названия
  конкретного старого матча. Справочник КХЛ остаётся общим с РУ (как и НХЛ).
- Проверка несовпадения видео и сценария: срабатывает только при повторных ясных
  упоминаниях нескольких других команд, а не при одном неразобранном имени.
  Объясняет найденные и ожидаемые команды, не раскладывает неподходящее видео
  почти целиком в первый разбор.
- Сохранённые настройки общие для всех шаблонов. Старые записи доступны без
  ручного переноса; одноимённые варианты сохраняются с указанием исходного профиля.
  Применение настроек не меняет спорт, сценарий, таймлайн и выбранные матчи.

## Распознавание и словари

Первый проход локальной узбекской модели использует beam_size=5 вместо 1 и
словарную подсказку уже с начала распознавания. Подсказка содержит имена, команды
и термины, но не текст сценария, результаты и статистические числа. Выборочный
повторный проход проверяет также названия матчей и Telegram. Ключ кеша учитывает
новые параметры и подсказку; после обновления старая запись распознаётся заново.
Это может занять больше времени. Файлы моделей заново скачивать не требуется.

Добавлены 55 ассоциаций UEFA и Узбекистан с английскими, русскими и узбекскими
названиями. Базовый словарь содержит 72 имени игроков шести сборных этого кейса.
Имена игроков и тренеров из очищенного сценария дополнительно попадают в подсказку.
Это не полный мировой справочник игроков и не автоматически актуальные заявки.
Источники названий указаны в football_names.py и football_players.py; статистика
и спортивные утверждения сценариев не добавляются в базу фактов.

## Проверка пользовательских материалов

UEFA: на присланных сохранённых планах воспроизведена ошибка Telegram после
объединения. Исправленное объединение: 5 разделов, 127 строк, 30 вставок,
371.3667 секунды. Повторный разбор имеющегося ASR с новыми правилами находит
границы 0.84 / 34.40 / 143.86 / 243.14 / 358.00 / 400.64,
три основных ставки, три повтора и Telegram в начале/конце.
Часть нечётких комбинированных ставок требует локальной проверки.

NHL: проект/сценарий и назначенные записи — Toronto–Islanders,
Philadelphia–Pittsburgh, Colorado–Los Angeles. В ASR другой выпуск:
Carolina–Florida, Toronto–Montreal, Boston–Rangers. Автоматически менять проект
пользователя на другой сценарий нельзя. Проверка теперь сообщает несовпадение.
С соответствующим речи ранее присланным сценарием найдено 5 разделов:
0–47.86 / 47.86–179.88 / 179.88–286.14 / 286.14–360.48 / 360.48–429.28.
Найдены три представления, три ставки и три повтора. Неуверенное второе имя и
нечёткие рынки вынесены в отдельную проверку. Проверена генерация архивных
запросов на фактических распознанных фразах.

Нейросетевой повторный прогон WAV с новыми параметрами локально не выполнялся:
проверялись фактический кеш ASR, разметка, контракты вызова декодера и кеша.
Исходного видео ведущего и полных записей матчей для полного пользовательского
рендера нет. Полный экспорт на синтетических медиа покрыт существующим тестом.
Пользовательские проекты, тексты, транскрипты и медиа в репозиторий не включены.

## После обновления

Откройте проект и заново определите тайминги всего выпуска. Для указанного NHL
проекта сначала загрузите сценарий той записи, которую действительно читает
ведущий, и назначьте подходящие архивы. Проверенные ручные таймкоды по-прежнему
имеют приоритет; они не исправляют несовпадение содержания сценария и видео.
