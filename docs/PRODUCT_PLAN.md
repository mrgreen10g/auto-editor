# План продукта

## Обязательные настройки

Windows, локальная обработка, i5-11400F / GTX 1070 / 16 ГБ. Несколько исходных матчей внутри каждого разбора; один источник может использоваться в нескольких разборах. Пользователь не составляет таймкоды.

- Наезды ведущего 100% → 120%, часто, с промежутками, вне игровых вставок.
- Синхронное сокращение пауз, очистка голоса от шума, лёгкая цветокоррекция, тихая музыка с приглушением под речь.
- Мягкие переходы между игрой и ведущим; анимированные вход/выход и слабое плавное покачивание всех плашек.
- Конкретные названные события подбираются по смыслу. Для общих рассуждений подходят обычные игровые фрагменты соответствующей встречи.
- Возможность посмотреть и исправить выбор до экспорта. Исходники и принятый тестовый ролик не перезаписываются.

## Этапы

1. **0.1 принята пользователем:** монтаж из готовых клипов, разметка речи, эффекты, очистка голоса, Windows-сборка. Остаётся без изменений в main.
2. **0.2 одним обновлением:** автоматический поиск голов, несколько исходных матчей внутри разбора, новый понятный интерфейс. Отдельную 0.1.1 не выпускаем. Разработка в version-0.2.
3. **Приёмка 0.2:** сначала поиск на полной записи СКА — «Лада», сравнение с четырьмя уже одобренными событиями. Затем другая запись, затем несколько источников в одном разборе. Измерить скорость и память на компьютере пользователя. Наличие интерфейса нескольких записей не означает, что все типы трансляций уже проверены.
4. Чтение документов сценария/материалов, встроенный видеоплеер, удобное редактирование монтажной шкалы.
5. Полный выпуск из нескольких разборов: дисклеймер, карточки матчей, вступление, повтор прогнозов, Telegram, подписка и лайк.

В текущей среде есть четыре вырезанных клипа, но нет полной исходной записи матча. До её повторной загрузки приёмочный поиск по всей записи не считается завершённым.

## 0.3 — замечания после пользовательского теста

- Голов может не быть в распознанном табло: игра подбирается независимо от счёта, затем из других загруженных встреч с приоритетом нужной команды. Архив явно помечается.
- Краткие отсылки к прошлым матчам тоже получают вставки. Резервные сцены по возможности не повторяются подряд.
- Короткие фактические плашки; травмы и ручные тексты сохраняются. Новый хоккейный стиль и отдельная карточка матча с пользовательскими логотипами.
- Auto Editor — новое название без привязки к виду спорта. Футбол через шаблоны остаётся будущим этапом.
- Автоповорот с проверкой нескольких кадров, необязательные даты, скрытые готовые клипы, подсказки, понятное редактирование текста без ложной кнопки проверки контекста.
- Следующий пользовательский прогон: повторить поиск для проблемного блока, оценить резервные сцены, графику, автоповорот и повторы.

Идеи после приёмки: настройка частоты игровых вставок; встроенный просмотр всей монтажной последовательности; итоговый отчёт о точных и архивных заменах; сохранённые стили оформления.

## 0.4 — исправления после следующего пользовательского теста

Этот раздел заменяет противоречащие ему правила 0.3.

- Запрещён резерв из неигровых сцен. Проверка непрерывных участков льда с движением, отсутствие слабого резерва «любая сцена». Переходы ограничены игровыми границами.
- Счёт имеет приоритет перед общими кадрами, даже при приблизительной секунде гола. Слабые кандидаты остаются на проверку; точность проверяется на исходной записи.
- Удалены служебные подписи архивных и обычных кадров из видео; происхождение видно в редакторе.
- Компактные плашки сверху слева, размеры по тексту; длинные травмы остаются широкими. Карточка команд только на ведущем.
- Архивные и общие вставки распределяются между доступными источниками; точные события остаются в нужной встрече.
- Реализованы три частоты обычных вставок и редактируемая дорожка с перемещением, обрезкой, заменой эпизодов, добавлением/удалением графики, отменой/повтором, сохранением в проекте и полным встроенным предпросмотром со звуком.
- Проект хранит ссылки на исходники: проверка доступности и восстановление путей из папки. Экспорт использует ту же дорожку, что и предпросмотр.

Дальше: приёмочный тест на полном исходном обзоре и трёх встречах, измерение скорости на компьютере пользователя; затем сохранённые стили и сборка полного выпуска. Не расширять на футбол до стабилизации текущего подбора.

## Приёмка 0.4 и следующий этап

По последнему пользовательскому тесту основные функции 0.4 приняты: все голы стоят на местах, частота меняет количество вставок, автоповорот и монтаж работают. Остались пять небольших поправок к времени, перемотке, графике и стыкам. Это обновляет прежние пункты об ожидаемой пользовательской приёмке.

Следующая пользовательская версия — **0.5: единый ролик из 2–4 разборов с переходами между матчами**, вместе со всеми пятью поправками. Отдельную пересборку 0.4 с косметическими изменениями пользователь не запрашивает. Подробности и проверяемые условия: [план версии 0.5](VERSION_0_5_PLAN.md).

Уточнение этапов пользователем: вступление и заключение добавляются отдельным следующим этапом только после успешной проверки объединённых разборов в 0.5. Текущий этап включает пять поправок после теста 0.4.
