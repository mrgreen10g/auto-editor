# 0.7.17rc2

Исправлен цикл «Найти голы» перед определением таймингов.

- Упоминание «мой выбор стал интереснее» внутри вступления к разбору больше
  не обрывает поиск фраз для игровых вставок. Остановка происходит при явном
  объявлении прогноза, например «Мой выбор — …» или «Основной прогноз — …».
- Завершённый поиск хранится отдельно от списка вставок. Пустой результат
  больше не означает, что поиск не запускался. Состояние сохраняется в проекте
  и пересчитывается при изменении сценария, записей или настроек ручных вставок.
- Один разбор и весь выпуск используют одинаковую проверку готовности в
  интерфейсе и при подготовке монтажа. Это относится к РУ хоккею, УЗ хоккею,
  футболу и боям. Ошибки чтения исходников и неподтверждённые эпизоды не
  приравниваются к успешному пустому поиску.
- Повторный поиск незавершённых разборов сохраняет подбор остальных блоков.
- В УЗ хоккее призывы к подписке и объявления прогнозов исключаются также
  перед общим подбором архивных вставок, а не только в резервном алгоритме.

Проверки: регрессия раннего упоминания выбора, порядок счёта исходной записи,
переход интерфейса к таймингам, подготовка монтажа с пустым завершённым поиском,
все четыре шаблона, сохранение/открытие проекта, изменение материалов,
обработка ошибок сканирования и сохранение остальных разборов.

Для ранее застрявшего проекта достаточно повторить поиск в новой версии;
удалять записи первой встречи или остальные найденные эпизоды не требуется.
Проверка пользовательского проекта выполнена по его сценарию и метаданным.
Исходных видеозаписей в приложенном архиве нет, их детектор здесь не запускался.
