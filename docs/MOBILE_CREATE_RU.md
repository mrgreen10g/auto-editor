# Создание выпуска с телефона — 0.8.4

Откройте в Mini App раздел «Выпуск». Выберите родительскую папку на Windows-сервере, при необходимости создайте вложенные папки, задайте название новой папки выпуска. Выберите РУ/УЗ, шаблон и сохранённые настройки. Существующие папки выпуска не перезаписываются.

Внутри появятся «Ведущий», «Матчи», «Сценарий», «Результат» и mobile-draft.json. Список черновиков сохраняется в профиле Windows. После перезапуска откройте редактор и выберите нужный черновик в Mini App.

1. Сценарий: вставьте текст либо загрузите TXT (UTF-8) / DOCX. Нажмите «Сохранить и определить разборы», проверьте и при необходимости исправьте названия. Для изменения сценария после назначения записей сначала уберите записи из черновика; сами файлы при этом не удаляются.
2. Ведущий: ссылка на видео Google Диска или загрузка с устройства. Доступ к Drive-файлу должен иметь Google-аккаунт, подключённый в редакторе. Можно добавить несколько частей ведущего в нужном порядке.
3. Матчи: выберите разбор, вставьте ссылку на отдельное видео YouTube. Укажите участников архивной записи, если они не определятся из названия. Для боёв укажите бойца. Пара прогноза и участники архивной записи — разные поля. Также можно загрузить запись с устройства.
4. Настройки: сохранённый набор включает звук, музыку, логотипы и параметры изображения. Постоянные материалы берутся из набора выбранного шаблона; можно выбрать другую папку на сервере.
5. Сводка: проверьте ведущего, разборы, число записей, настройки. Кнопка создания проекта сохраняет текущий проект редактора, открывает новый и переводит в «Процесс». Запускайте поиск фрагментов; дальнейшие проверки и рендер работают как раньше. Папкой рендера по умолчанию станет «Результат» внутри выпуска.

## Передача файлов

С устройства файлы передаются частями по 2 МБ. До конца передачи держите Mini App открытой: iPhone может приостановить браузер в фоне или при блокировке экрана. После обрыва снова выберите тот же файл — продолжение начнётся с подтверждённого места. Если сессия Telegram истекла, сначала переоткройте Mini App. Максимум: 50 ГБ для видео, 8 МБ для файла сценария. Ограничения свободного места проверяются отдельно.

Ссылки скачивает сам сервер; Telegram можно закрыть. Одновременно скачивается/проверяется один файл, чтобы не перегружать сервер. Отмена сохраняет частичные данные. После перезапуска сервера продолжение запускается явно кнопкой «Продолжить». Auto Editor должен работать под тем же пользователем Windows.

Скачивание YouTube зависит от доступности записи с сервера. Закрытые записи, ограничения входа или региона могут потребовать другой источник. В сборке есть загрузчик и JavaScript-компонент, но работа со всеми ссылками не гарантируется. Произвольные адреса сайтов не принимаются.

После создания проекта черновик становится доступен для повторного открытия проекта. Подробные правки созданного монтажа выполняются в существующих разделах редактора; расширенная мобильная правка запланирована следующим этапом.
