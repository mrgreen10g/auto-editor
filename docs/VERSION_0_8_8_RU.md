# 0.8.8rc1

Добавлены шаблоны «РУ → Футбол · Shorts» и «УЗ → Бои · Shorts». Формат 9:16, отдельные наборы оформления, общий импорт/монтаж Shorts. Боевые плашки без логотипов; условие пятираундового боя сохраняется в прогнозе и повторе ставок. Реальные будущие результаты боёв из сценария не проверяются и не становятся базой фактов приложения.

Английский справочник UFC уже существовал (3214 имён). Добавлены 271 соответствие английского и узбекского написания, включая варианты Kavanagh/Kavana и Ramazan/Ramazon. Снимок рейтингов https://www.ufc.com/rankings от 22.10.2026 покрыт справочником (201 уникальное имя). Это редакционные варианты транслитерации, а не официальная узбекская локализация и не автоматически обновляемый рейтинг.

## Поиск разборов

Сначала проверяются служебные метки `Разбор1`, `Разбор2`, … без верхнего ограничения. Слово `Разбор` и положительное целое число пишутся слитно, с указанным регистром. `Разбор 1` меткой не является. Метку ставить на строке пары до/после её названия либо отдельной строкой непосредственно перед/после заголовка (пустые строки допустимы). Номера должны быть уникальными; порядок определяется сценарием. Метки не входят в текст блоков, названия или плашки. Исходный редактируемый сценарий сохраняет их для повторного разбора.

Пример:

```
Разбор1 Арсенал — Челси
Текст первого разбора.
Разбор2 Ливерпуль — Эвертон
Текст второго разбора.
Итоги
Повтор прогнозов.
```

Правило общее для РУ/УЗ, футбола/хоккея/боёв, лонгов/Shorts. ТОП-5 сохраняет обязательные правила своего рейтингового формата; служебные метки удаляются перед его обработкой, не заменяя номера мест.

Если меток нет, работает прежний поиск. При импорте корневой папки дополнительно учитываются точные самостоятельные заголовки, совпадающие с названиями вложенных папок пар. Подпапка `shorts` и символические ссылки исключаются. Подсказки сохраняются в мобильном черновике для повторного разбора; повторный импорт обновляет их. Папка определяет принадлежность материалов разбору, но не доказывает участников архивной записи.

Неоднозначная метка, повтор номера или пустой разбор требуют исправить сценарий; программа не угадывает пару. Для надёжного отделения концовки используйте `Итоги` / `YAKUN`.

Этап 2 живого монтажа этим обновлением не реализован. Сохраняются требования: лонги и Shorts, синхронизация, undo/redo, допустимая однократная подготовка прокси без повторного рендера при последующих правках.
