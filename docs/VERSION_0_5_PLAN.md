# Версия 0.5 — несколько разборов в одном ролике

Текущий согласованный этап: объединение 2–4 разборов одной записи, пять правок после принятого теста 0.4 и визуальные переходы между матчами. Пользователь отдельно уточнил: **вступление и заключение добавляются после успешной проверки этого этапа**.

Реализованы:

- общий проект с отдельными сценариями, исходными матчами и правками блоков; устойчивые идентификаторы и перестановка ↑/↓;
- последовательный автоматический поиск речи, исключение повторяющегося монтажного запаса на стыках;
- общий поиск эпизодов с повторным использованием одной записи и сохранением принятого выбора;
- единая монтажная дорожка, переходы к разделам, редактирование и сохранение обратно по блокам;
- общий предпросмотр и MP4, непрерывная музыка, переход «Следующий матч»;
- время ММ:СС.сс и визуальная обрезка выбранного эпизода с кадрами и маркером;
- исправленная перемотка после правок: устаревшее видео не воспроизводится, обновление сохраняет курсор;
- крупная золотая карточка основной ставки, уменьшенная на 18% карточка команд;
- непрерывные соседние игровые вставки; короткие щели до 0,35 с заполняются последним проверенным кадром игры, без захвата неигрового материала;
- чтение старых проектов и сохранение совместимых правок 0.4.

Проверки: порядок 2–4 блоков, сохранение общего/локального монтажа, повторное использование кэша, формат времени, границы обрезки, реальные FFmpeg-стыки без вспышки ведущего и без тишины, графика, Windows GUI с обрезкой и перемоткой. Пользовательская приёмка проводится на полной записи с несколькими разборами.

Следующий этап после приёмки: отдельные шаблоны вступления и заключения, дисклеймер первым, Telegram, повтор тех же ставок, подписка и лайк по речи ведущего. Конкретные постоянные материалы предоставляет пользователь. Футбол, самостоятельное скачивание матчей и полноценный аудиоредактор остаются за рамками 0.5.
