# 0.8.9rc2 — боевые иллюстрации и гибридный сбор выпуска

## Бои: РУ/УЗ, лонг/Shorts

Подбор остаётся иллюстративным: видео идущего боя показывается под описание боя, без поиска совпадения конкретного приёма с текстом. Общие фразы о поединке тоже могут использовать записи его участников; известная принадлежность отдельному бойцу сохраняется. Вступление, концовка, прогнозы и призывы не создают боевые вставки.

Детектор v7 допускает единичный сбой OCR между последовательными показаниями таймера при достаточном окружающем подтверждении. Длинные пропуски, неподвижный/противоречивый таймер, отсутствие движения и склейки внутри фрагмента исключаются. Кандидаты длиннее и расположены плотнее; на дорожке для боёв используются отдельные интервалы между вставками. Убрано дополнительное подавление из-за чередования архивных источников. Это не классификатор всех видов рекламы: качество на конкретной трансляции требует проверки.

Чтобы применить новый подбор к уже сохранённому выпуску, запустите «Найти эпизоды боя» и пересоберите тайминги. Явный повторный поиск имеет прежнее предупреждение о замене подбора. При обычном открытии ручные пропуски и принятые границы не сбрасываются. Завершённый анализ кадров используется повторно при построении новых кандидатов.

Боковые боевые плашки перенесены справа налево. Центральные представления пар, ставки и полноэкранные переходы сохраняют свои позиции; вертикальные плашки уже находятся слева.

## Папки и смешанные материалы в Mini App

«Сохранить текст и заново определить разборы» теперь повторно сопоставляет папки со всеми найденными парами и добавляет их файлы без дублей. Корни материалов сохраняются в черновике. Для прежних импортов корень восстанавливается из сохранённых данных, включая родительскую папку для Shorts. Ручные назначения и удаления сохраняются; файлы исчезнувшего разбора остаются на диске. Созданный проект не перезаписывается — используется обновлённая копия.

Серверную папку можно открыть до появления сценария или ведущего. В списках файлов есть «Добавлю позже / сохранить уже добавленное». К текущему черновику можно подключать дополнительные папки; при повторном анализе проверяются все подключённые корни. Недостающие материалы добавляются с устройства, по ссылке либо отдельным серверным файлом. Новый ведущий дополняет уже добавленные части: ненужную старую запись следует убрать из списка явно.

Если в подключённых папках есть неоднозначности или архив не имеет сведений об участниках, они остаются видимыми в сводке; чужая пара не выбирается молча.

## Telegram в редакторе

В «Список элементов и добавление вручную» добавлена Telegram-вставка. По умолчанию выбирается материал Telegram из настроек выпуска / выбранной папки постоянных материалов. Можно выбрать другой файл из этой папки. После добавления доступны начало и конец на дорожке, начало внутри исходника и замена пути к видео на сервере. Проверка границ выполняется до сохранения.

Доступны удаление, undo/redo и сохранение проекта. Используется существующее оформление: анимация для лонга, полноэкранная вставка для Shorts, голос ведущего сохраняется. Изменение видеоматериала по-прежнему может требовать подготовки предпросмотра; это не завершение этапа 2.
