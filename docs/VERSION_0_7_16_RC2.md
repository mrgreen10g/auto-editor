# 0.7.16rc2 — границы речи при объединении разделов

Исправлена блокировка сборки полного выпуска с сообщением «Повреждена дорожка речи» при исправном аудио. В `crop_padding_at_next_speech` вычитание абсолютных времён оставляло погрешность за границей кадра: сохранялся интервал порядка 1e-14 секунды, который после пересчёта в общие координаты становился нулевым. Аналогичный риск был в `trim_overlap`.

Обе функции теперь округляют вычисленную границу к кадру перед сравнением и обрезкой. Проверка положительной длины интервалов сохранена. Сообщение валидатора уточняет, что речь идёт о монтажной разметке, а не повреждении аудиофайла. Изменение общее для всех профилей; модель и кеш ASR менять не нужно.

На присланных пяти планах RU-выпуска воспроизведена прежняя ошибка. После исправления объединение и проверка проходят: 5 разделов, 122 строки, 371.4 секунды, сумма длительностей media также 371.4 секунды. Полная WAV-дорожка декодируется FFmpeg без ошибок. Исходного видео ведущего и оригинальных анимаций в архиве нет, поэтому полный пользовательский видеорендер не заявляется проверенным.

Добавлены четыре регрессии в `tests/test_episode_frame_boundaries.py`: обрезка хвоста, обрезка начала, объединение и сериализация, сохранение отказа на действительно некорректном интервале. Полный локальный набор: 245 тестов, OK. Также FFmpeg собрал реальное аудио по исправленному плану: 371.4 секунды; все 122 строки сохранены. Windows CI и EXE проверяются после публикации этого коммита. Пользователь 2026-09-29 прямо разрешил публикацию исправления в work-uz-combat и запуск Windows-сборки.
