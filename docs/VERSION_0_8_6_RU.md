# 0.8.6 · Монтаж по общей шкале времени

В центре раздела «Монтаж» — плеер и таймлайн. Список элементов и ручное добавление свернуты; фильтр по виду элемента убран. Дополнительные настройки сохранены.

«Весь выпуск» готовит полный черновой предпросмотр со всеми плашками и вставками. «Выбранный участок» готовит ровно указанный диапазон без ограничения 20 секундами. Это серверная сборка в пониженном разрешении, а не мгновенный браузерный композитор. Большой выпуск может готовиться несколько минут. Готовое превью передаётся потоком с перемоткой без загрузки целого файла в память телефона. Повторный просмотр той же версии переиспользует готовый предпросмотр в текущей сессии.

Время под плеером, курсор таймлайна, маркеры и поля вырезки относятся ко всему выпуску. Встроенный в браузер счётчик локального видео может начинаться с нуля; ориентируйтесь на крупное время выпуска под плеером. Нажмите на шкалу для перемотки или используйте ползунок и шаг ±1 кадр. Вне подготовленного диапазона курсор перемещается, но для просмотра кадра сначала подготовьте диапазон или весь выпуск.

Поставьте начало и конец кнопками «Начало здесь» / «Конец здесь», затем вырежьте диапазон. Границы привязываются к кадрам дорожки 30 fps. Минимальная длина вырезки — 0,15 секунды; целый раздел через вырезание не удаляется. Речь, плашки и видео сдвигаются вместе. Исходники сохраняются. История поддерживает отмену/возврат.

Масштаб увеличивает таймлайн; его можно прокручивать горизонтально. Нажмите на элемент для выбора и редактирования. У выбранного элемента можно перетянуть край (длительность) или середину (положение). Правка сохраняется при отпускании. Пересекающиеся элементы разнесены на отдельные строки. Точные границы также доступны в полях выбранного элемента. После правки старое превью скрывается; новый просмотр нужно подготовить заново.

«Логотипы команд» показывает наличие файлов по каждой команде и сколько логотипов применяется. Выберите папку на сервере для автоматического сопоставления или файл отдельно для команды. Выбор новой папки заново сопоставляет все команды. Можно убрать назначенный логотип; изменения отменяются через историю.

На поддерживаемых версиях Telegram запрашивается полноэкранный режим, отключается свайп сворачивания страницы, учитываются безопасные области экрана. Нажатие на свободное место снимает фокус с текстового поля и скрывает клавиатуру. Поведение системной клавиатуры и полноэкранного режима дополнительно зависит от клиента Telegram/iOS.

Dynamic Island / экран блокировки в этой версии не добавлены. Для них нужен нативный iOS-компаньон с ActivityKit/WidgetKit, Live Activities и серверными обновлениями через APNs. Обычная Telegram Mini App не имеет API для собственных Live Activities.
