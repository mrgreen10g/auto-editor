# Создание выпуска с телефона: контрольная точка

Разработка возобновлена поверх исправлений 0.8.3rc2. Текущие изменения и ограничения описаны в `VERSION_0_8_4_RU.md`; этот документ сохраняет историю контрольной точки.

Разработка приостановлена по запросу пользователя 19 октября 2026 года для исправления ошибок УЗ-выпусков.

Код сохранён в ветке `checkpoint/mobile-create-20261019`, коммит `b62891b2c22afc7cda20b99280f6f564443c4774`.

Реализованы черновики выпуска, создание папки сервера, загрузка ведущего с устройства или Google Drive, сценарий, материалы матчей, сводка и повторное использование архивов. Этот этап ещё не выпущен: последняя сборка 39238408804 не прошла интеграционный тест Mini App. При возобновлении сначала изучить этот тест и проверить загрузки/восстановление на Windows.

Исправление УЗ выпущено отдельно на основе рабочей 0.8.3rc1. Изменения мобильного создания временно исключены из рабочей ветки обычным коммитом, история и контрольная ветка сохранены. При возвращении переносить изменения мобильного этапа поверх исправлений, не откатывать исправления УЗ.
