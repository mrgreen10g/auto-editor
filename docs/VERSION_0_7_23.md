# 0.7.23rc1 — полноэкранный Telegram, пары и субтитры РУ Shorts

Telegram в обоих шаблонах Shorts снова занимает весь вертикальный кадр. Вертикальная запись канала больше не уменьшается до размеров широкого игрового окна. Пропорции источника и голос ведущего сохраняются; игровые вставки и субтитры не накладываются на рекламу. Для горизонтального материала используются поля без растяжения.

Определение основной пары РУ Shorts учитывает команды в разных абзацах, прогноз и формулировки о текущем сопернике. Упоминания прежних матчей со счётом не становятся основной парой. При неоднозначности сохраняется возможность указать строку «Матч: Команда — Команда»: заголовок нормализуется для сопоставления речи. Лимит числа разборов не введён.

## Субтитры

В «Оформление и звук» добавлена настройка «Субтитры · РУ Shorts (экспериментально)». По умолчанию выключена. Выбор сохраняется в проекте и шаблонах настроек. Функция применяется только к РУ Shorts; лонги и УЗ шаблоны не меняются.

Короткие группы до четырёх слов, белый жирный текст с тёмной обводкой и золотым выделением текущего слова. Субтитры расположены ниже основных плашек. Во время полноэкранного Telegram скрываются. Это отдельный слой рендера, а не плашки, требующие подтверждения.

Новая разметка сохраняет времена слов русского распознавания. После вырезания пауз/дублей времена пересчитываются; сборка нескольких разборов и повторное открытие проекта сохраняют синхронизацию. Старые проекты без времён слов показывают фразовые субтитры с приблизительным распределением времени и без подсветки слова. Для точной подсветки заново определите тайминги: сохранённое распознавание используется повторно.

После включения/выключения субтитров обновите предпросмотр. Повторное распознавание при одном переключении не требуется. Включение не добавляет ещё один прогон ASR. Ошибки распознавания могут попасть и в субтитры; функция экспериментальная.

## Проверки

Регрессии: основная пара из раздельных абзацев, заголовок «Матч:», старые сценарии, сохранение настройки, сохранение и перенос времён слов, вырезание пауз, скрытие во время Telegram, предпросмотр. Реальный FFmpeg-рендер проверяет полноэкранный вертикальный Telegram и субтитры с включённой/выключенной настройкой, включая пути с апострофом. Проверка GUI включает переключатель.

Приложенный пользовательский сценарий проверен локально. Он и пользовательские медиа в репозиторий не включены. Визуальные проверки новых субтитров используют технические источники; полного нового ASR пользовательского шортса в этой проверке нет.
