# 0.7.21rc2 — ориентация Shorts и повторный поворот камеры

В присланном проекте разрешение было правильным: 1080×1920. После подготовки ведущего FFmpeg сохранял display matrix с поворотом 90°, хотя сами пиксели уже были повёрнуты правильно. Финальная сборка применяла метку ещё раз. Последующее масштабирование наследовало неквадратные пиксели SAR 256:81, поэтому файл 1080×1920 отображался как 16:9.

Исправления:

- Матрица поворота удаляется из уже подготовленной дорожки без перекодирования видео и звука. Исходная запись камеры не меняется.
- Исправляются и промежуточные файлы, сохранённые предыдущей версией: удалять кэш речи или повторять поиск матчей не требуется.
- На входе финальной сборки повторный автоматический поворот отключён, а матрица явно сброшена.
- Выход всегда имеет квадратные пиксели. Перед сохранением проверяются размеры, соотношение пикселей и отсутствие остаточного поворота.
- Эти проверки действуют и для предпросмотра, и для готового MP4; горизонтальные шаблоны сохраняют своё разрешение.

Регрессии проверяют запись с камерной меткой 90° по обоим путям подготовки ведущего, повторный запуск со старым кэшем, положение цветовых маркеров кадра, звук и длительность. Проверка исходных пикселей нужна потому, что одни размеры 1080×1920 не выявляют такой дефект.

После установки откройте сохранённый проект и заново создайте предпросмотр или экспорт под новым именем. Ранее экспортированный MP4 обновление автоматически не меняет.
