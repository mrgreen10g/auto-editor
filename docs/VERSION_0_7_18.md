# 0.7.18rc1

## Граница первого разбора

Исправлена ошибка, при которой позднее упоминание прошлой встречи могло
стать началом первого разбора, а его первые десятки секунд попадали во вступление.
Идентификаторы NHL теперь сравниваются точно, а не как похожие слова.
Добавлен вариант распознавания «Рейнджер с». При равных совпадениях выбирается
ранняя пара, проверяется начало основного текста; поиск назад не захватывает
Telegram или переходную фразу. Старые автоматические дорожки пересчитываются.
Подтверждение плашки без изменения её времени больше не фиксирует ошибочную
автоматическую позицию при новом анализе. Явные ручные правки сохраняются.

## Игроки NHL

- Офлайн-справочник содержит 834 уникальных имени из опубликованных составов
  всех 32 клубов, включая дополнительные имена вне основного состава.
  Источник и дата приведены в `hockey_editor/nhl_roster.py`.
- Добавлены распространённые русские написания для 160 игроков, варианты
  распознавания и дополнительные транслитерационные поисковые формы.
  Неоднозначная фамилия не превращается в угаданное полное имя.
- Только имена, встречающиеся в сценарии, передаются в подсказку распознавания.
  Числа, результаты и утверждения сценария в подсказку не попадают.
- Короткие перечисления объединяются по три имени; обсуждения состава,
  формы и роли игрока получают плашки с именами. Имеющаяся статистическая
  плашка не дублируется второй плашкой с тем же упоминанием.
- Словарь не добавляет в видео сведения о текущих клубах, травмах или трансферах.
  Составы — снимок на дату источника, не автоматически обновляемая база.

После обновления повторите определение таймингов. Модель речи скачивать
заново не требуется; распознавание будет выполнено с новой подсказкой имён.

Проверены ранняя/поздняя пара, разделённое распознаванием название, защита
Telegram, черновая разметка, карточки игроков, неоднозначные фамилии,
отсутствие ложного игрока из `back-to-back`, сохранение ручных правок,
а также повторное построение дорожек по предоставленным данным проекта.
Полный рендер с оригиналом ведущего не проверен: оригинала нет в архиве.
