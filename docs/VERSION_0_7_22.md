# 0.7.22rc1 — РУ хоккей Shorts и Telegram в верхнем окне

Добавлен шаблон «Хоккей · РУ Shorts», с русским распознаванием и существующей хоккейной логикой матчей, голов, статистики, игроков, прогнозов и ожидаемого счёта. Выход 720×1280 или 1080×1920. Лимита на число разборов нет; несколько пар можно обозначить отдельными заголовками «Команда — Команда». Одному разбору не нужны искусственные вступление и итоги. При неоднозначной паре импорт просит заголовок вместо догадки.

Для обоих шаблонов Shorts:

- Игровые кадры и Telegram плавно появляются в верхнем окне, ведущий плавно смещается ниже. Анимация управляется настройкой переходов.
- Telegram занимает верхнее окно вместо полного экрана, сохраняя голос ведущего. Фразы о ссылке и подводка входят в рекламу; игровые вставки исключаются из этого интервала.
- Поиск Telegram учитывает выровненный текст и контекст публикации в канале, включая рекламу внутри разбора и искажённое название сервиса в УЗ речи. Речь о подписке на YouTube сама по себе не считается рекламой Telegram.
- РУ перечисления заброшенных шайб группируются в одну плашку статистики. Надписи шаблона русские.
- Настройки, сохранение проекта, предпросмотр и экспорт поддерживают новый профиль; исправление ориентации камеры из 0.7.21rc2 сохранено.

## Использование

Выберите «Хоккей · РУ Shorts», загрузите ведущего и полный сценарий через настройки полного выпуска. Добавьте записи матчей и материал Telegram, затем определите тайминги. В старом УЗ Shorts-проекте повторно определите тайминги и обновите предпросмотр: старый рендер не содержит исправления рекламы.

УЗ Shorts пока поддерживает футбол. УЗ хоккей и бои остаются отдельными горизонтальными шаблонами. Перенос подтверждённых архивов кнопкой «Shorts · взять матчи из лонга…» пока доступен только для УЗ футбола; РУ хоккей использует обычное добавление записей и поиск голов.

## Проверки и ограничения

Регрессии проверяют импорт одного и нескольких РУ разборов, выбор основной пары вместо архивного соперника, сохранение проекта, отсутствие обязательного пустого вступления/концовки, статистику, ставку, ожидаемый счёт, середину Telegram и исключение игровых кадров из рекламы. Реальные FFmpeg-тесты проверяют вертикальные размеры, звук, два окна, промежуточное смещение ведущего при плавном переходе и отсутствие повторного поворота камеры. GUI-проверка включает новый профиль.

Пользовательские материалы используются только локально. Проверка сценария и компоновки на исходной записи не равна полному новому нейросетевому распознаванию. В приложенном архиве нет записей матчей или материала Telegram: рендерные проверки используют технические заглушки для этих источников.
