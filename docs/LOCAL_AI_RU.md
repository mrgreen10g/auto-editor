# Локальный ИИ: первый пробный этап (0.8.9rc9)

Без платных API. Qwen3 1.7B Q4_K_M (Apache-2.0), llama.cpp b11960 (MIT), CPU Windows x64. Модель скачивается отдельно (1 282 439 264 байта), не раздувает архив программы. Загрузки проверяются SHA-256. Интернет нужен для установки; сценарий и распознанная речь обрабатываются на локальном 127.0.0.1 с временным ключом. Установка не требует администратора.

Оформление и звук → Локальный ИИ → Настроить локальный ИИ → Установить компоненты → Проверить на этом ПК. Затем включить «Перепроверять спорный текст после разметки». По умолчанию выключено. В ручной проверке есть отдельная кнопка для выбранной плашки. Подсказка видна и в мини-апке.

Это первая пробная интеграция, не завершение всего этапа автоматического принятия. Модель сравнивает сценарий и распознанный текст; не слушает звук, не доказывает границы и не снимает ручную проверку. Три результата: смысл совпадает / возможно расхождение / недостаточно данных. После редактирования исходного текста старая подсказка скрывается. Ручные подтверждения не перезаписываются. Для безопасного автоматического принятия нужна отдельная оценка ложных подтверждений на реальных РУ/УЗ материалах.

Режим для сервера пользователя: Xeon E5-2640 v4, 8 доступных логических процессоров, 8 ГБ RAM, Windows Server 2019. Два CPU-потока, пониженный приоритет, контекст 2048, без GPU. Модель выгружается после прохода. Требуется минимум 3 ГБ свободной RAM перед запуском; если памяти недостаточно или запуск не удался, обычная проверка продолжает работать. Автоматически максимум 5 новых фрагментов на проход, текст до 2400 символов, ограничение времени отдельного запроса 90 с. Результаты кэшируются. Длинный текст остаётся для человека. Скорость и совместимость конкретного Windows Server 2019 проверяются кнопкой на целевом ПК, Windows CI не заменяет этот замер.

Логи runtime: %LOCALAPPDATA%/HockeyAutoEditor/local-ai/runtime.log. Не использовать вывод модели как доказательство чисел, имён, направления ставки или таймингов. План всех 17 направлений: AI_ROADMAP_RU.md.
