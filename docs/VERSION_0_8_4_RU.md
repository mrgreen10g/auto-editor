# 0.8.4 — создание выпуска с телефона

В Mini App появился раздел «Выпуск»: выбор и создание папки сервера, шаблон РУ/УЗ, сценарий TXT/DOCX или текст, ведущий с Google Диска либо с устройства, ссылки YouTube для архивных записей и сводка перед открытием проекта. Можно повторно использовать архив из другого мобильного выпуска. Передача с устройства требует открытой Mini App; после обрыва выберите тот же файл для продолжения. По ссылке файл скачивает сервер. Для Google Диска нужен доступ подключённого Google-аккаунта к файлу; YouTube может отказать из-за ограничений доступа.

Альтернатива — «Собрать из готовой папки сервера». Для Shorts выбирайте папку лонга с папкой shorts. Исходные видео остаются на месте; неопределённых участников архивных записей можно исправить в сводке материалов.

На ПК в экспорте: «Отправить на Google Диск…», выбор папки, прогресс, пауза/продолжение и копирование ссылки. Используется та же очередь загрузки, что и в Mini App. В плеерах добавлена скорость 1–2×; итоговое видео не меняется.

Уведомления обозначаются парами команд. На каждом событии бот отправляет новое сообщение с обычным уведомлением и удаляет своё предыдущее сообщение этого выпуска. Звук зависит от настроек телефона; сообщения старше лимита удаления Telegram остаются. Старые сообщения, созданные прежними версиями без сохранённого ID, автоматически не удаляются.

Перевод УЗ → РУ теперь выполняется по коротким фразам с единым кодированием префикса языка. Добавлены повторная попытка и проверки чисел, посторонней религиозной темы и повторов. Старый кэш переводов не используется. Если перевод не прошёл проверку, показывается сообщение и исходная фраза, а не выдуманный русский текст. Это не гарантирует точность каждой фразы; на исходную речь и монтаж перевод не влияет.

Исправления УЗ из 0.8.3rc2 сохранены. Мобильная разработка возобновлена поверх них из контрольной ветки checkpoint/mobile-create-20261019.
