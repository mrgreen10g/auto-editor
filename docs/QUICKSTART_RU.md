# Первый запуск

1. Скачайте архив Windows-сборки и нажмите на него правой кнопкой мыши → «Извлечь все». Выберите обычную папку на диске, например «Документы\Монтаж».
2. Откройте извлечённую папку `HockeyAutoEditor` и дважды нажмите `HockeyAutoEditor.exe`. Не переносите EXE отдельно от папки `_internal`.
3. В строке «Ведущий» нажмите «Выбрать» и укажите исходное видео с голосом. Можно запись всего выпуска до 15 минут.
4. В «Название матча» напишите команды. В большое поле вставьте сценарий одного разбора.
5. Нажмите «Добавить вставки» и выберите готовые игровые фрагменты. В таблице проверьте слова, к которым они привязаны. Кнопка «Изменить привязку» позволяет вписать точную фразу из сценария — секунды указывать не нужно.
6. На вкладке «Оформление и звук» при необходимости выберите поворот ведущего. Новые эффекты, наезды до 120% и обычная очистка голоса включены по умолчанию. Музыку можно добавить отдельным файлом.
7. Нажмите «Определить тайминги». Вкладка «Проверка разметки» покажет фразы и автоматически найденное время. Для нужной фразы можно изменить текст плашки; пустой текст отключает её.
8. Нажмите «Сохранить проект». Файл `.hockeyproj` хранит настройки и ссылки на исходники. Он не содержит самих видео: не удаляйте и не перемещайте их отдельно от проекта.
9. Нажмите «Собрать MP4», выберите папку и новое имя результата. Во время обработки окно остаётся доступным; кнопка «Отменить» останавливает работу.
10. Когда экспорт закончится, нажмите «Открыть результат». Рядом с видео будут SRT-субтитры и файл разметки JSON; для просмотра ролика достаточно MP4.

## Если у вас несколько разборов

Нажмите «Добавить разбор», вставьте его сценарий и добавьте относящиеся к нему вставки. Запись ведущего общая для проекта. Первая версия экспортирует выбранный разбор отдельно; объединение всего выпуска будет добавлено далее.

## Если что-то не получилось

- «Не найден файл»: выберите его заново; проект мог быть перемещён отдельно от исходников.
- «Не найдена фраза»: измените привязку вставки на слова, которые есть в сценарии. Например, для ответного гола ведущий может говорить «смог сравнять», не называя счёт.
- «Проверить» рядом с фразой: два варианта анализа разошлись. Проверьте соответствие сценария речи и итоговый ролик.
- Результат уже существует: задайте другое имя, чтобы сохранить предыдущую версию.
- Ошибка обработки: откройте вкладку проверки → «Открыть папку разметки». Там есть журналы `base-render.log` и `final-render.log`; их можно прислать для диагностики.

Сейчас программа принимает готовые игровые вставки. Загружать полный матч как короткую вставку не следует: поиск голов в полном матче будет отдельным следующим модулем.
