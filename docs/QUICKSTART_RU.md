# Auto Editor 0.3 — первый запуск

1. Скачайте архив AutoEditor-Windows из успешной сборки version-0.3. Распакуйте его, затем вложенный ZIP в новую папку. Старую версию сохраните отдельно.
2. Запустите AutoEditor.exe. Папка _internal должна остаться рядом.
3. Откройте прежний проект или добавьте ведущего, название разбора, сценарий и исходные матчи. Дата необязательна; команды указывайте в порядке табло.
4. Нажмите «Найти голы», даже если проект раньше уже обрабатывался в 0.2. Новый поиск подберёт и обычную игру без табло, и резервные сцены вместо пропусков. Старые строки «Ведущий» заменятся новым подбором после повторного поиска.
5. Во вкладке «Игровые эпизоды» можно посмотреть или заменить выбор. Статус «Архив» означает кадры из другой встречи. Резервные сцены уже разрешены для монтажа; программа не требует подтверждать каждую. «Оставить ведущего» явно отключает выбранную вставку.
6. Нажмите «Определить тайминги», затем перейдите к экспорту и соберите MP4 под новым именем.

## Оформление и звук

Здесь находятся автоповорот ведущего, эффекты, музыка, логотипы и выбор качества. В новых проектах поворот автоматический. В старом проекте ранее заданный ручной поворот сохраняется; при желании выберите «Автоматически».

Чтобы добавить логотипы, укажите название разбора как «Команда — Команда», затем выберите два изображения в разделе «Карточка матча». Поддерживаются PNG, JPEG и WebP. Для лучшего результата используйте крупные изображения; очень маленькое размытие программа не сможет восстановить без потери деталей. Без логотипа выводятся инициалы команды.

«Разрешить архивные кадры из других матчей» включено по умолчанию. Если выключить, программа будет искать замену только внутри нужной записи. Архивные кадры подписываются в готовом видео.

Готовые клипы скрыты. Для старых проектов их можно включить настройкой «Показывать и использовать готовые вставки». Включённые готовые клипы сохраняют ручные привязки; отключите их, если хотите проверить полностью автоматический подбор.

## Плашки

Фразы с результатами, бросками, прогнозами и условиями сокращаются до кратких фактов. Текст о травмах сохраняется. Нажмите дважды на фразу во вкладке «Речь и плашки», чтобы изменить текст; пустое поле отключает плашку. Этот экран служит редактированию, а не просмотру видеофрагментов. Замечания автоматического выравнивания речи доступны в журнале.

Наведите курсор на «?» рядом с карточкой или на основные кнопки — появится подсказка.

## Сохранение

Сохраните проект под предложенным именем с -0.3. Видео остаются отдельными файлами: переносите их вместе с проектом. Новые проекты версии 3 открываются в программе 0.3. Экспортируется выбранный разбор, а не весь выпуск сразу.

Первый тест обновления — тот же блок с проблемными встречами. Проверьте наличие игровых замен, подписи архивных кадров, короткие плашки и ориентацию ведущего.
