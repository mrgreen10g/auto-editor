# Auto Editor 0.4 — первая проверка

1. Скачайте `AutoEditor-Windows`, распакуйте его и вложенный ZIP в новую папку. Старую версию оставьте отдельно.
2. Запустите `AutoEditor.exe`. Папка `_internal` должна лежать рядом.
3. Откройте старый проект. Проект хранит ссылки на видео, сами записи остаются на вашем компьютере. Если программа сообщает о пропавших файлах, нажмите **«Восстановить ссылки»** и выберите папку с исходниками. Неоднозначные совпадения не заменяются автоматически.
4. Убедитесь, что выбраны видео ведущего, сценарий и исходные матчи. Ведущий нужен для таймингов речи, но не для поиска голов в матчах.
5. Нажмите **«Найти голы»** повторно. Это заменит старый выбор эпизодов; принятые видеофайлы не перезаписываются. Просмотрите оставшиеся сомнительные места в списке. Если игровой сцены не нашлось, программа не использует зрителей как резерв: можно добавить запись или оставить ведущего.
6. В настройках выберите частоту **«Реже / Обычно / Чаще»**. Это влияет на обычные перебивки. Отсылки к конкретным голам сохраняются.
7. Нажмите **«Определить тайминги»**, затем **«Открыть монтажную дорожку»**.

## Работа с дорожкой

- Верхняя дорожка — ведущий и голос; она сохраняет синхронизацию.
- Средняя — игровые вставки, нижняя — плашки.
- Выберите элемент щелчком. Перетаскивайте середину для сдвига, край — для обрезки. Точные секунды можно ввести справа и нажать **«Применить правку»**.
- Для вставки можно выбрать **«Заменить игровой момент»** из найденных эпизодов всех загруженных матчей. Границы обрезки ограничены выбранной игровой сценой.
- **«+ Игра»** и **«+ Плашка»** добавляют элемент в позицию красного курсора. Щёлкните свободное место на дорожке, чтобы установить его.
- Текст справа редактирует плашку; подпись игры видна только в редакторе.
- **«Удалить»**, **«↶ Отменить»**, **«↷ Повторить»** позволяют исправить выбор. Пересечения игровых вставок не принимаются.
- **«Собрать предпросмотр»** создаёт полный ролик 640×360 с речью, эффектами и графикой. Дождитесь готовности, затем нажмите ▶. Ползунок и щелчок на дорожке меняют время. После правки соберите предпросмотр заново.
- Нажмите **«Применить к проекту»**, закройте окно и сохраните проект через **Ctrl+S** с новым именем. Иначе правки останутся только в текущем сеансе.
- Перейдите к экспорту. Финальное видео использует сохранённую дорожку, включая ваши исправления.

## Что проверить в прежнем блоке СКА — «Лада»

Нет ли стадиона/зрителей/судей вместо игры; совпадают ли четыре описанных гола; чередуются ли архивные источники; остаётся ли карточка команд только на ведущем; короткие плашки находятся сверху слева. Никаких служебных надписей поверх игры быть не должно.

В новых проектах поворот определяется автоматически. В старых сохраняется выбранный ручной угол — при необходимости переключите на **«Автоматически»**.

Если сменить исходники, сценарий, сокращение пауз или частоту вставок после редактирования, потребуется обновить анализ: прежняя дорожка может не соответствовать новой речи. Сохраняйте отдельную копию проекта перед такими изменениями.
