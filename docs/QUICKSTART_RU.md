# Первый запуск 0.2

## 1. Открываем программу

Скачайте архив HockeyAutoEditor-Windows из успешной сборки version-0.2. Распакуйте его, затем распакуйте вложенный HockeyAutoEditor-0.2.0-Windows.zip в НОВУЮ папку. Версию 0.1 сохраните отдельно. Внутри запустите HockeyAutoEditor.exe. Папку _internal рядом с ним не удаляйте.

## 2. Добавляем материалы

На шаге «Материалы» выберите запись ведущего, вставьте сценарий одного разбора и его название. Старый проект можно открыть кнопкой «Открыть проект». При сохранении программа предложит имя с -0.2, чтобы сохранить прежнюю копию.

В карточке «Исходные матчи» нажмите «+ Записи». Для первой проверки выберите одну полную запись СКА — «Лада». Укажите команды в порядке табло: слева, затем справа; добавьте дату. Позже этой же кнопкой можно добавить остальные встречи, на которые ссылается ведущий. «Из проекта» добавляет уже загруженную запись в другой разбор без повторной загрузки.

Если тестируете автоматический поиск на старом стартовом проекте, уберите из КОПИИ проекта четыре готовых клипа в карточке «Готовые вставки». Иначе их фразы останутся привязаны к готовым клипам и не будут участвовать в поиске. Сами файлы на диске сохранятся.

## 3. Находим голы

Нажмите «Найти голы». Программа сама прочитает табло, найдёт кандидатов и свяжет их с фразами сценария. Таймкоды заранее готовить не нужно. Поиск длинной записи может занять заметное время; ход работы виден внизу окна и в журнале. Его можно отменить.

На шаге «Проверка», вкладка «Игровые эпизоды», выделенные строки требуют внимания. Дважды нажмите на строку: выберите кандидат, нажмите «Посмотреть видео», затем снова откройте строку и нажмите «Использовать эпизод». При необходимости поправьте начало, конец и положение гола внутри исходной записи. Просмотр откроется в обычном видеоплеере Windows.

Если подходящего эпизода нет, выберите «Оставить ведущего». Программа не возьмёт вместо него случайный гол другого матча. Можно добавить фразу вручную кнопкой «+ Фраза».

Если счёт не обнаружен, вернитесь в «Материалы», выделите запись и нажмите «Область счёта». Обведите две цифры счёта без игрового таймера, сохраните область и повторите поиск. Если показанный кадр не содержит табло или графика нестандартная, пришлите пример для настройки следующей версии.

## 4. Размечаем речь и собираем ролик

После проверки эпизодов нажмите «Определить тайминги». Программа найдёт фразы в записи ведущего и подготовит монтаж. Во вкладке «Речь и плашки» можно изменить текст плашки двойным щелчком по фразе.

На отдельном экране «Оформление и звук» уже включены наезды до 120%, переходы, анимация плашек и очистка голоса. Здесь же выбираются музыка, поворот исходника и размер видео.

Перейдите к «Экспорту», нажмите «Собрать MP4», выберите новое имя файла. Затем откройте результат и проверьте речь и голы. Экспортируется текущий разбор, а все остальные остаются в проекте. Кнопка «Сохранить проект» сохраняет материалы и выбор эпизодов.

Проект содержит ссылки на видео, а не сами видео. При переносе сохраняйте проект и исходники вместе. Проект 0.2 открывается в версии 0.2; для старой программы оставьте прежний проект 0.1.
